## Descripción
Las tareas de la práctica 2 tienen como objetivos conocer el entorno Gymnasium y realizar un estudio de unos cuantos algoritmos básicos, para ello a partir de un código proporcionado aqui: https://github.com/ldaniel-hm/eml_tabular/blob/main/MonteCarloTodasLasVisitas.ipynb tenemos que modificarlo para obtener un agente y añadir  la gráfica   f(t) = len(episodiot). Esta gráfica es un buen indicador de aprendizaje dado que nos indica que está aprendiendo a alcanzar la meta más rápido, en problemas que no penalizan los errores o los pasos, puede ser un gran indicador para diferenciar algoritmos.
